Thank you for your interest in contributing!

Please follow these guidelines before opening a pull request or issue:

- Create an issue describing the feature or bug you want to implement.
- For features: include motivation, UX sketch or description, and acceptance criteria.
- For bug fixes: include steps to reproduce, expected behavior, and a minimal test case.
- Run existing tests (if present) and ensure formatting checks pass.

When opening a pull request, link the related issue and provide a clear description of changes.
